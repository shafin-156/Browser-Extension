> A lightweight Firefox extension that unlocks disabled web elements, enables blocked input fields, and provides a quick full-screen mode for any webpage or video element.

---

## 🌟 Core Features

`Enable Plus` combines two essential browser utilities into one seamless extension:

### 1. 🔓 Element & Input Unlocker (`Enable Plus`)
* **Remove Disabled Attributes:** Scans and strips `disabled`, `readonly` from buttons, input fields, forms, and context menus.
* **Restore Interactions:** Enables grayed-out buttons, blocked copy-paste actions, and restricted form submissions.
* **Automated Injection:** Runs automatically or via a single-click trigger to restore locked page features.

### 2. 🖥️ Universal Full-Screen Mode (`Make Full Screen`)
* **Force Full Screen:** Instantly toggle full-screen view for the entire active tab or target specific embedded elements (e.g., videos, canvas elements, frames).
* **Keyboard Shortcut Support:** Quick toggle using custom hotkeys or the popup toolbar menu.
* **Distraction-Free Mode:** Cleanly hides browser chrome and unnecessary page distractions with a single click.
